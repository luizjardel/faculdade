# Critérios de conclusão

Uma fase não deve ser considerada concluída apenas por assistir às aulas.

Para avançar, é importante:

1. Compreender os conceitos apresentados.
2. Conseguir explicar o funcionamento dos recursos estudados.
3. Resolver exercícios sem depender constantemente de tutoriais.
4. Desenvolver o projeto proposto.
5. Conseguir identificar e corrigir erros no próprio código.

## Direção profissional

Consolidar TypeScript como uma segunda grande base de desenvolvimento, complementando Java e Spring Boot, com possibilidade de atuar tanto no Backend quanto no Full Stack.

**Regra principal:** Priorizar compreensão, prática e construção de projetos. Não avançar apenas para acumular conteúdos.
